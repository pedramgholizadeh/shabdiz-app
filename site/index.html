هر چیزی که یک شب سینمایی لازم دارد

از ورود بدون رمز تا پخش هم‌زمان با زیرنویس؛ زیرساخت طوری طراحی شده که تمرکز تو فقط روی فیلم باشد.

هم‌زمانی دقیق

زمان پخش از سرور محاسبه می‌شود. با هر ورود، پلیر از همان ثانیه سالن جلو می‌رود و هر ۱۵ ثانیه دوباره همگام می‌شود.

ورود با ایمیل یا مهمان

بدون رمز عبور؛ کد شش‌رقمی موقت به ایمیل ارسال می‌شود. ثبت‌نام اجباری نیست — می‌توانی مهمان تماشا کنی و بعداً سابقه‌ات به حسابت منتقل شود.

پلیر حرفه‌ای mpv

پشتیبانی از MKV، MP4 و فرمت‌های رایج روی اندروید، تلویزیون‌های اندرویدی (با کنترل ریموت) و دسکتاپ، همراه با بارگذاری زیرنویس فارسی.

تقویم شمسی و ساعت تهران

تاریخ و ساعت سانس‌ها در پنل ادمین به شمسی ثبت می‌شود و در اپلیکیشن هم به همان شکل نمایش داده می‌شود.

ورود فقط در زمان پخش

لینک پخش تنها در بازه سانس و برای کاربران واردشده ارائه می‌شود؛ خارج از آن، سالن بسته است.

      - run: flutter build apk --release
        working-directory: app
      - run: flutter build apk --release --split-per-abi
        working-directory: app

          name: shabdiz-universal-apk
          path: app/build/app/outputs/flutter-apk/app-release.apk

FAQ

پرسش‌های پرتکرار

شب‌دیز روی چه نسخه‌ای از اندروید نصب می‌شود؟

حداقل اندروید ۶ (API 23). APK به‌صورت مستقیم از GitHub Actions ساخته می‌شود و نیازی به فروشگاه اپلیکیشن ندارد.

روی تلویزیون‌های اندرویدی هم اجرا می‌شود؟

بله. همان APK روی Android TV نصب می‌شود و در لانچر تلویزیون نمایش داده می‌شود؛ رابط کاربری برای کنترل با ریموت (D-pad) طراحی شده است — پخش/توقف با دکمه وسط ریموت و نمایش منوها با جهت‌نما.

پخش چطور با بقیه هم‌زمان می‌شود؟

سرور بر اساس ساعت شروع سانس، ثانیه جاری پخش را محاسبه می‌کند. اپلیکیشن همان نقطه را در پلیر جلو می‌برد و هر ۱۵ ثانیه با API دوباره همگام می‌شود.

زیرنویس فارسی پشتیبانی می‌شود؟

بله. برای هر سانس می‌توان لینک زیرنویس ثبت کرد؛ پلیر آن را بارگذاری می‌کند و دکمه روشن/خاموش زیرنویس در صفحه پخش وجود دارد.

می‌توانم در توسعه مشارکت کنم؟

بله، پروژه با مجوز MIT منتشر شده است. Issue و Pull Request روی مخزن GitHub پذیرفته می‌شود. راهنمای توسعه در AGENTS.md و README قرار دارد.
